## 🌟 Основные возможности

### 🎶 Чистый звук и полные треки (Full Audio + Spotify Source)
- **Только полные композиции** (от 2 до 8+ минут) без 30-секундных демо-превью и без сторонней рекламы.
- **Новый источник Spotify:** встроенные топ-чарты Spotify Hits, чарты России и мировые тренды с автоматическим мостом воспроизведения полных версий.
- Мгновенный поиск по огромной базе композиций и ремиксов всех жанров.
- Поддержка HLS и прямого потокового воспроизведения высокого качества.

### 🌐 Мультиязычный интерфейс (RU / EN)
- Мгновенное переключение языка интерфейса (Русский 🇷🇺 / English 🇬🇧) в один клик в настройках.
- Полный перевод навигации, плеера, настроек и системных уведомлений.

### 🛡️ Нативный C# лаунчер и правовая защита
- **Нативный бинарный лаунчер (C#):** мгновенный тихий старт без консольных окон `cmd.exe` или скриптов PowerShell.
- **Zero Telemetry & Local Storage:** нулевой сбор данных, библиотека хранится только на диске пользователя.
- **Правовая чистота:** встроенные [Политика конфиденциальности](PRIVACY_POLICY.md) и [Правовой отказ от ответственности](DISCLAIMER.md) с явным указанием об отсутствии аффилированности со Spotify AB и Dodo Brands.

### 🌊 «Моя волна» (Smart Autoplay & Wave)
- **Умный авторандом:** запустите любую песню (например, *«Джентльмены»*, *«Captain»*, *«Девочка в каре»*), и алгоритм автоматически продолжит воспроизведение похожими треками в этом же стиле.
- Бесшовная подгрузка новой музыки до того, как закончится текущая очередь.

### 🌌 Реактивные живые видео-обои (Web Audio API)
- 5 анимированных полноэкранных сцен:
  - 🟢 **Северное Сияние (Aurora):** плавные светящиеся волны с неоновым шлейфом.
  - 🟠 **Огненный Пульс (Dodo):** динамические плазменные сферы.
  - 🟣 **Киберпанк Сетка (Synthwave):** ретро-солнце и бесконечная неоновая сетка.
  - 🔵 **Глубокий Космос (Galaxy):** космическая туманность и звёздное скопление.
  - 🔴 **Ночной Фонк (Phonk):** агрессивные басовые пульсации и световые струны.
- **Синхронизация с битом:** частицы и волны оживают и физически пульсируют под реальные низкие частоты (Bass) играющей песни.
- Опция *«Обои движутся только когда играет музыка»* и автоматический подбор цвета интерфейса в тон видео-обоев.

### 👤 Страницы артистов и дискография
- Персональные профили исполнителей: официальные аватары (включая **KME / kme_dota** с фирменной шляпой), статистика и биография.
- Полные альбомы и сборники релизов (*«Jungle»*, *«MVP»*, *«blade»*, *«Best of KME»* и др.).
- Кнопка перехода к первоисточнику трека на платформе (SoundCloud / Audius).

### 💾 Постоянное сохранение библиотеки и скачивание треков (v1.1)
- **Постоянная дисковая база данных:** треки, лайки, плейлисты и история прослушиваний сохраняются в файл `dodospoti_library.json` в профиле пользователя (`AppData/Roaming/DodoSpoti`) и никогда не теряются при перезапусках.
- **Лайки на каждой карточке:** сердечки ❤️ на карточках позволяют мгновенно добавлять любимые песни в библиотеку в один клик.
- **Прямое скачивание MP3:** удобная кнопка скачивания аудио прямо в плеере для прослушивания офлайн.
- **Стабильный системный порт 58240:** исключает сброс пользовательских сессий и настроек.

### 🪟 Глубокая системная интеграция Windows
- **Системные уведомления Windows (Action Center):** нативные Toast-уведомления с логотипом DodoSpoti и системным звуком вместо стандартных alert-окон.
- **Системный трей Windows:** управление плеером из панели задач около часов (Play/Pause, следующий/предыдущий трек, сворачивание).
- **Медиа-клавиши клавиатуры (Windows SMTC):** кнопки Play, Pause, Next, Prev на клавиатуре или гарнитуре управляют плеером на уровне всей системы Windows.
- **Системный оверлей громкости Windows:** отображение текущего трека, артиста и обложки.

### 🔄 Система обновлений через GitHub (v1.1)
- Интерактивный бейдж статуса в верхней панели приложения.
- Раздел проверки новых версий в «Настройках» с вызовом официального GitHub Releases API в один клик.

## 🚀 Быстрый старт

### Вариант 1. Портативная версия (Без установки)
1. Скачайте архив релиза **`DodoSpoti-v1.1-win32-x64.zip`** со страницы [GitHub Releases](https://github.com/foridorpo-blip/DodoSpoti/releases).
2. Распакуйте архив в любую удобную папку.
3. Запустите **`DodoSpoti.exe`**. Приложение готово к работе!

### Вариант 2. Запуск и сборка из исходников

Требования: [Node.js](https://nodejs.org/) v18+ на Windows x64.

```bash
# 1. Клонирование репозитория
git clone https://github.com/foridorpo-blip/DodoSpoti.git
cd dodospoti

# 2. Установка зависимостей
npm install

# 3. Запуск десктопного приложения в режиме разработки
npm start

# 4. Или запуск серверной веб-части
npm run server
```

## 🛠 Технологический стек

- **Core Desktop:** Electron 30, Node.js, Express, CORS
- **Audio & DSP:** HTML5 Audio, HLS.js, Web Audio API (`AnalyserNode`, FFT)
- **Visuals:** HTML5 2D Canvas Realtime Render Engine (60 FPS)
- **Windows Integration:** Windows SMTC (`MediaSession`), Shell Tray, Windows Notification Toasts
- **Data & Streaming:** SoundCloud API v2 Transcoding Engine, Audius Discovery API, GitHub Releases API
