# DodoMusic 🎵

Свободный, быстрый и открытый музыкальный плеер нового поколения для Web, Desktop и Android.

## 🚀 Особенности

- 🌐 **Кроссплатформенность:** Web-версия, автономный Desktop-клиент и нативный Android APK.
- 📱 **Android Lock Screen Widget:** нативный виджет с переключением треков, плей/паузой и обложками на экране блокировки.
- 🎤 **Караоке и тексты:** синхронизация строк с аудиопотоком в реальном времени.
- 🌊 **Моя Волна:** бесконечный микс похожих треков на основе ваших предпочтений.
- 🎨 **Интерактивные живые обои:** адаптивные визуальные темы и настраиваемый интерфейс.
