# DodoSpoti v1.0 — Первый официальный релиз 🚀

Первый полнофункциональный десктопный релиз **DodoSpoti** для Windows x64.

### ✨ Ключевые возможности:
* **Только чистые и полные композиции:** потоковое воспроизведение без рекламы и без 30-секундных обрезков.
* **Умная волна (Smart Autoplay & Wave):** бесконечный интеллектуальный автомикс треков на основе выбранной песни.
* **5 живых реактивных видео-обоев (Web Audio API):**
  * *Северное Сияние* (Aurora)
  * *Огненный Пульс* (Dodo)
  * *Киберпанк Сетка* (Synthwave)
  * *Глубокий Космос* (Galaxy)
  * *Ночной Фонк* (Phonk)
  * Обои физически реагируют и пульсируют под реальный бас музыки с возможностью настройки силы баса и прозрачности интерфейса.
* **Страницы артистов и дискография:**
  * Профили артистов (включая **KME / kme_dota** с официальным аватаром в коричневой шляпе федора).
  * Поддержка популярных хитов (*«Джентльмены»*, *«Дагон»*, *«Slam»*, *«Солнечный день»* и др.).
  * Официальные сборники и альбомы (*«Jungle»*, *«MVP»*, *«blade»*, *«Best of KME»*).
  * Кнопка перехода к первоисточнику трека.
* **Глубокая системная интеграция Windows:**
  * Системный трей Windows (около часов) с контекстным меню.
  * Нативные Windows Toast-уведомления (Action Center) с логотипом DodoSpoti.
  * Windows SMTC: поддержка мультимедийных клавиш клавиатуры (Play/Pause/Next/Prev) и всплывающего системного оверлея громкости Windows.
* **Автопроверка обновлений через GitHub:**
  * Индикатор актуальности в шапке и сайдбаре.
  * Проверка новых версий в один клик через GitHub Releases API.
