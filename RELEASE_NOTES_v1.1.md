# 🚀 Релиз DodoSpoti v1.1 — Постоянное сохранение библиотеки, скачивание треков и системная интеграция Windows

Встречайте большое обновление **DodoSpoti v1.1**! В этой версии мы добавили долгожданную систему сохранения треков, прямое скачивание MP3, сердечки лайков на всех карточках и глубокую интеграцию с Windows.

---

### 🌟 Что нового в v1.1:

#### 1. 💾 Постоянное сохранение треков и библиотеки на диск
- Вся ваша медиатека, плейлисты, лайки и история теперь сохраняются напрямую в локальный JSON-файл базы данных:  
  `%APPDATA%\DodoSpoti\dodospoti_library.json`.
- Ваши треки и любимая музыка **больше никогда не пропадают** при перезапуске приложения или перезагрузке компьютера.

#### 2. ❤️ Лайки прямо на карточках треков
- На каждой карточке в каталоге, результатах поиска и дискографиях артистов появилось сердечко `❤️`.
- Добавить трек в «Любимые» или убрать из них теперь можно в один клик без перехода на страницу трека.

#### 3. 📥 Скачивание треков в MP3
- В плеер добавлена кнопка **«Скачать трек»** (`#downloadCurrentBtn`).
- Скачивайте полные композиции прямо на свой компьютер для прослушивания офлайн.

#### 4. 🔒 Стабильный системный порт 58240
- Внутренний сервис приложения теперь привязан к фиксированному порту `58240`, что гарантирует постоянную сохранность `localStorage`, кэша и сессий браузера.

#### 5. 🪟 Системные уведомления Windows и интеграция
- **Windows Action Center (Toast):** Всплывающие уведомления Windows при смене трека, добавлении в избранное и проверке обновлений.
- **Встроенные Glass Toast:** Красивые матовые уведомления внутри интерфейса плеера с подсветкой и неоновым свечением.
- **Media Keys (Windows SMTC):** Управление воспроизведением (Play, Pause, Next, Prev) с клавиатуры и мультимедийных кнопок мыши/гарнитуры.
- **Windows System Tray:** Иконка в трее возле часов для быстрого сворачивания и управления музыкой в фоне.

#### 6. 🔄 Обновление до v1.1
- Встроенная проверка актуальности через официальный GitHub API (`foridorpo-blip/DodoSpoti`).

---

### 📦 Установка:
1. Скачайте архив **`DodoSpoti-v1.1-win32-x64.zip`** ниже.
2. Распакуйте в удобную папку.
3. Запустите **`DodoSpoti.exe`** и наслаждайтесь музыкой!
